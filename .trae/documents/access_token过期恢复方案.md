# Access Token 过期恢复方案计划

## 一、摘要

本项目已实现较完整的 AT 刷新机制（refresh_token 预刷 + 3天 keepalive + 401 强刷 + 密码重登兜底），但在多条兜底链路上存在缺口，导致 AT 在某些场景下无法自动恢复。本方案聚焦于**补全失效兜底链**，确保 AT 过期后能在所有已知场景下自动恢复或自动补号，最大限度减少人工介入。
